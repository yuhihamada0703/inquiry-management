# 要件定義書

## プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | Inquiry Management（問い合わせ管理アプリ） |
| 目的 | 顧客からの問い合わせを一元管理し、対応状況をチームで共有する |
| 対象ユーザー | カスタマーサポート担当者 |
| 作成日 | 2026-06-11 |

---

## 背景と課題

問い合わせ対応をスプレッドシートやメールのみで管理すると、  
対応漏れ・二重対応・進捗の不透明さが発生しやすい。  
本アプリはそれらを解消するためのシンプルな問い合わせ管理ツールとして位置づける。

---

## 機能要件

### 問い合わせ管理（CRUD）

| # | 機能 | 説明 |
|---|------|------|
| F-01 | 問い合わせ登録 | 件名・内容・問い合わせ者名・メール・優先度・期限を入力して登録 |
| F-02 | 問い合わせ一覧表示 | 登録された問い合わせをカード形式・テーブル形式で表示 |
| F-03 | 問い合わせ詳細表示 | 選択した問い合わせの全情報を表示 |
| F-04 | 問い合わせ編集 | 登録済み情報を更新 |
| F-05 | 問い合わせ削除 | 不要な問い合わせを削除（確認ダイアログあり） |

### ステータス管理

| # | 機能 | 説明 |
|---|------|------|
| F-06 | ステータス表示 | 未対応 / 対応中 / 完了 の3種類 |
| F-07 | ドラッグ&ドロップによるステータス変更 | カードをカラム間でドラッグして移動 |
| F-08 | ステータスフィルタ | ステータスで絞り込み表示 |

### 並び替え・フィルタ

| # | 機能 | 説明 |
|---|------|------|
| F-09 | 優先度順ソート | 高・中・低の優先度順に並び替え |
| F-10 | 期限順ソート | 期限が近い順・遠い順に並び替え |
| F-11 | キーワード検索 | 件名・内容でフリーワード検索 |

### データ永続化

| # | 機能 | 説明 |
|---|------|------|
| F-12 | データベース保存 | MySQLへ永続化 |
| F-13 | ページネーション | 一覧は20件/ページで表示 |

---

## 非機能要件

| 項目 | 要件 |
|------|------|
| パフォーマンス | 一覧取得は 500ms 以内に応答 |
| 可用性 | EC2 + RDS 構成でサービス提供 |
| セキュリティ | CORS設定、環境変数による機密情報管理 |
| ブラウザ対応 | Chrome / Edge 最新版 |
| レスポンシブ | PC・タブレットに対応 |

---

## 制約条件

- AWSはEC2とRDSのみ使用（ALB・ECS等は使用しない）
- 認証機能はスコープ外（将来拡張として考慮）
- データベースはMySQL 8.0

---

## スコープ外

- ユーザー認証・ロール管理
- メール通知
- 添付ファイル管理
- 外部サービス連携（Slack等）
